# 42_cursus

> My complete journey through the **42 Madrid Common Core**, organized by milestones.

This repository contains all the projects I have completed during the **42 Madrid** curriculum. Instead of separating each project into an individual repository, I chose to organize them following the official progression of the Common Core, making it easier to understand how the skills evolve from one milestone to the next.

Each milestone introduces new concepts and increases the technical difficulty, gradually covering low-level programming, algorithms, system programming, graphics, networking, object-oriented programming, and web technologies.

---

# About 42

42 is an innovative software engineering school with a project-based, peer-to-peer learning methodology. There are no traditional classes or teachers. Students develop their skills by solving increasingly complex programming challenges, collaborating with peers, and defending their work during evaluations.

The Common Core emphasizes:

- Low-level programming in C and C++
- Algorithms and data structures
- Unix system programming
- Memory management
- Computer graphics
- Networking
- System administration
- Object-oriented programming
- Teamwork and code reviews
- Writing clean, maintainable, and efficient code

The Common Core develops competencies in:

- Imperative Programming
- Algorithms & Artificial Intelligence
- Unix & System Programming
- Graphics
- Network & System Administration
- Object-Oriented Programming
- Web Technologies
- Software Engineering Rigor
